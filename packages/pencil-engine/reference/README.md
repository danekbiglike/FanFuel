Задания для imagegen: (1) оставить только чёрное графитовое тело с завитком и внутренней фактурой, убрать канистру, лицо, конечности и фон; (2) оставить только лаймовую канистру с буквой F, ручкой, чёрным контуром и исходной направленной штриховкой, убрать персонажа и фон. В обоих заданиях запрошены сохранение пропорций, минимальные изменения и прозрачный alpha-фон. Образец отдельного контура также был сгенерирован, но отклонён: он стал похож на размазанный графит и не отражает исходный край.

Важно: два новых файла — **синтетические интерпретации**, а не извлечённые слои исходного файла. Модель восстановила скрытые участки и изменила часть штрихов. Нельзя автоматически трассировать их и объявлять результат точной реконструкцией. Сравнивать будущий рендер в первую очередь с `oily-original.png`; раздельные изображения помогают увидеть направление, плотность, цвет и характер штриха.
