# CHANGELOG.md

## 2026-09-24 — добавлено наблюдение за сетью VM

- Windows каждые две минуты проверяет доступность обеих VM и их связь с роутером через мост; Codex уведомляет при подтверждённом сбое и восстановлении. Автоматическое вмешательство в сеть не настроено.

## 2026-09-24 — уточнена причина сетевого инцидента

- Почтовые порты на том же публичном IP были доступны извне, а веб-порты недоступны. Диагностика выявила потерю связи роутера с обеими VM через мост VirtualBox после сброса физической сетевой карты Windows. Переподключение мостового драйвера восстановило связь VM с роутером и публичный доступ к playground и основному сайту; точная первопричина зависания моста пока не доказана.

## 2026-09-24 — локальный Wi-Fi доступ к playground

- На edge добавлен отдельный LAN-only HTTP-вход к статическому playground, пока ПАКТ восстанавливает Static NAT. Поскольку iPhone не соединялся напрямую с edge VM, доступ с телефона организован через локальный мост на Windows-хосте. Публичные маршруты и основной сайт не менялись; upstream TLS проверяется.

## 2026-09-24 — ПАКТ подтвердил неисправность входящей трансляции

- Техническая поддержка подтвердила активную услугу Static NAT и сбой на своём пограничном шлюзе. Заявка №678149 передана сетевым инженерам; публичный доступ пока не восстановлен.

## 2026-09-24 — уточнена недоступность публичного playground

- Повторная внешняя проверка показала тайм-аут публичных 80/443 при исправной локальной цепочке VM и edge. Услуга внешнего IP (Static NAT) у ПАКТ уже подключена; требуется проверка её действующей привязки и входящего маршрута. Предыдущая запись о восстановлении относится только к доступу внутри локальной сети.

## 2026-09-24 — восстановлен доступ к playground и FanFuel

- После потери DHCP-адреса VM основной сайт и playground снова доступны через edge. За VM закреплён статический LAN-адрес с сохранением NAT SSH и резервной копией прежней сетевой конфигурации.
