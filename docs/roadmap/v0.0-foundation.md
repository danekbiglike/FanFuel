# v0.0 — Foundation

Цель: подготовить техническую основу, структуру и документацию для разработки без хаоса.

Статус: implemented.

Входит:

- структура monorepo;
- Docker Compose для локальной разработки;
- базовые контейнеры PostgreSQL и Redis;
- директория миграций;
- базовый UI kit skeleton;
- i18n skeleton с `ru` и `en`;
- базовые docs;
- healthchecks;
- шаблоны `.env.example`, `SECRETS.template.md`, `docs/SERVER_ACCESS.template.md`.

Не входит:

- production-код платежей;
- реальные кабинеты;
- реальные выплаты;
- публичный запуск.

Критерии готовности:

- разработчик может поднять dev окружение;
- структура пакетов и сервисов зафиксирована;
- документация описывает первые задачи;
- секреты не попадают в Git.

Риски:

- чрезмерное усложнение до появления MVP;
- отсутствие единого формата задач;
- смешивание платежной логики с доменом.

Зависимости:

- финальный выбор package manager;
- базовый Docker Compose;
- решение по auth policy.
