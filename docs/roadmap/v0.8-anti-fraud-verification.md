# v0.8 — Anti-fraud + Verification

Цель: снизить операционные и платёжные риски перед публичной бетой.

Входит:

- лимиты для Seller Lite;
- Seller Pro verification;
- risk flags;
- suspicious activity;
- audit logs;
- admin review queue;
- hold policy.

Не входит:

- advanced anti-fraud ML;
- автоматическая KYC-проверка без провайдера;
- скоринг как финальное юридическое решение.

Критерии готовности:

- риск-флаги создаются по событиям;
- лимиты применяются на уровне API;
- Seller Pro проходит проверяемый workflow;
- админ видит очередь review.

Риски:

- ложные срабатывания;
- недостаточные данные для проверки;
- блокировка честных продавцов.

Зависимости:

- seller balance;
- admin tooling;
- юридическая проверка лимитов.
