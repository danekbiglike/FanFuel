# v0.5 — Real Payment Provider Integration

Цель: подключить реального платёжного провайдера через абстракцию без привязки домена к одному оператору.

Входит:

- payment provider abstraction;
- tome adapter, если tome подходит после проверки;
- альтернативный adapter для ЮKassa/ЮMoney или mock;
- webhooks;
- idempotency;
- refunds;
- payouts;
- safe deal lifecycle.

Не входит:

- финальная юридическая модель без внешней проверки;
- production rollout для всех продавцов;
- рискованные категории.

Критерии готовности:

- все платежи идут через `PaymentProvider`;
- provider statuses маппятся в provider-agnostic statuses;
- webhook signature verification реализована;
- retries безопасны;
- операции аудируются.

Риски:

- провайдер не поддержит нужный safe deal/payout flow;
- требования 54-ФЗ/115-ФЗ окажутся сложнее ожидаемых;
- provider lock-in.

Зависимости:

- юридическая проверка;
- договорённость с провайдером;
- staging credentials.
