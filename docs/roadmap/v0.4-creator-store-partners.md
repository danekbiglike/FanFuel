# v0.4 — Creator Store + Partners

Цель: расширить `v0.3.5` live-only витрину автора до полноценной creator-commerce модели с партнёрской атрибуцией и промокодами.

Входит:

- развитие витрины стримера после базовых live-only секций, выбора продуктов и авторских подборок `v0.3.5`;
- расширение партнёрских товаров из базового выбора `v0.3.5` до полноценной атрибуции;
- промокоды;
- партнёрский процент;
- отслеживание продаж;
- расширенная аналитика для стримера и продавца поверх `v0.3.5` statistics/events;
- отображение доли автора для покупателя.

Не входит:

- сложный recommendation engine;
- многоуровневая партнёрская сеть;
- рекламный кабинет.

Критерии готовности:

- автор добавляет партнёрский товар в витрину;
- покупка корректно создаёт attribution;
- промокод влияет на цену по правилам;
- продавец видит продажи от авторов.

Риски:

- непрозрачная атрибуция;
- конфликт промокодов;
- некорректный расчёт доли автора.

Зависимости:

- Marketplace MVP;
- `v0.3.5 Aurora Refresh + Universal Profile + Studio Skins`;
- balance transaction model;
- API analytics endpoints.
