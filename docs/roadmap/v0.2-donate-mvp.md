# v0.2 — Donate MVP

Статус: `implemented`.

Цель: запустить минимальный поток доната с mock payment и OBS alert.

Входит:

- донат-страница автора;
- создание доната;
- тестовая оплата через mock provider;
- OBS alert widget;
- WebSocket event delivery;
- история донатов;
- цель сбора;
- топ донатеров.

Не входит:

- реальные платежи;
- фискализация;
- кастомный дизайнер алертов;
- расширенная аналитика.

Критерии готовности:

- донат создаётся и проходит через mock payment;
- OBS widget получает событие через WebSocket;
- цель сбора обновляется после успешного доната;
- повторные webhooks не дублируют донат.

Риски:

- потеря realtime-событий;
- отсутствие idempotency;
- небезопасные widget tokens.

Зависимости:

- auth/profiles;
- WebSocket gateway skeleton;
- mock payment adapter.
