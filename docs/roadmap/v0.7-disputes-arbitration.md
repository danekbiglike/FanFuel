# v0.7 — Disputes + Arbitration

Цель: реализовать понятный и управляемый процесс споров.

Входит:

- открытие спора;
- доказательства;
- сообщения в споре;
- решения админа;
- возвраты;
- удержания;
- рейтинг риска.

Не входит:

- автоматическое юридическое решение;
- сложная медиация;
- ML-антифрод.

Критерии готовности:

- покупатель может открыть спор в допустимый срок;
- продавец получает уведомление и срок ответа;
- админ фиксирует решение;
- refund/hold/payout отражаются в ledger;
- все действия пишутся в audit log.

Риски:

- спорные правила возвратов для цифровых товаров;
- недостаток доказательств;
- ручная нагрузка на админов.

Зависимости:

- SafeDeal lifecycle;
- file evidence storage;
- notification system.
