# v1.0 — Public Beta

Цель: controlled launch с реальными пользователями и ограниченным набором категорий.

Входит:

- production deployment;
- monitoring;
- backups;
- legal docs placeholders;
- support workflows;
- first real categories;
- controlled launch;
- onboarding продавцов и стримеров;
- операционные инструкции.

Не входит:

- масштабные микросервисы;
- нативные приложения;
- рискованные категории без проверки;
- fully automated arbitration.

Критерии готовности:

- production окружение развёрнуто;
- мониторинг и backups проверены восстановлением;
- support и moderation workflows описаны;
- реальные платежи разрешены только для проверенного scope;
- есть rollback plan.

Риски:

- недостаточная поддержка пользователей;
- юридические ограничения по категориям;
- рост споров после старта.

Зависимости:

- legal review;
- provider contracts;
- production observability;
- ручная операционная команда.
