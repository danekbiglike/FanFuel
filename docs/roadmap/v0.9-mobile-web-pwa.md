# v0.9 — Mobile Web / PWA

Цель: подготовить mobile-first опыт без нативного приложения.

Входит:

- mobile-first интерфейс;
- PWA;
- push strategy;
- адаптация кабинетов;
- улучшение UX для покупателей и продавцов;
- установка на домашний экран.

Не входит:

- iOS/Android native apps;
- глубокая офлайн-работа;
- сложная mobile analytics stack.

Критерии готовности:

- ключевые сценарии проходят на телефоне;
- PWA manifest и service worker настроены;
- пуши описаны юридически и технически;
- checkout, order и dispute удобно работают на mobile.

Риски:

- push-уведомления требуют согласий и юридической проверки;
- интерфейс кабинетов может стать перегруженным;
- разные ограничения браузеров.

Зависимости:

- стабильный web UX;
- notification model;
- i18n formatting.
