# v0.3 — Marketplace MVP

Статус: `implemented` для mock/local MVP.

Цель: дать продавцам возможность публиковать товары, а покупателям — оформлять заказы через mock safe deal.

Входит:

- категории;
- товары;
- карточка товара;
- seller profile;
- покупка товара;
- order lifecycle;
- mock safe deal;
- отзывы;
- базовая модерация товаров.

Не входит:

- рискованные категории;
- автоматическая выдача сложных цифровых товаров;
- реальные выплаты;
- сложная рекламная биржа.

Критерии готовности:

- продавец создаёт товар;
- покупатель оформляет заказ;
- оплата проходит через mock provider;
- заказ получает безопасные статусы;
- админ может скрыть товар.

Риски:

- смешивание order/deal/payment статусов;
- хранение файлов без access control;
- некорректная комиссия платформы.

Зависимости:

- S3/R2 abstraction;
- базовая модерация;
- payments skeleton.
