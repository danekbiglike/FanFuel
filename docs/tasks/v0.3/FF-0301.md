# FF-0301: Реализовать product categories

Статус: completed
Версия: v0.3
Приоритет: P0
Компоненты: services/api, infra/migrations, apps/web

### Цель

Создать категории marketplace.

### Контекст

Категории должны учитывать legal risk.

### Что нужно сделать

- Таблица `product_categories`.
- API categories.
- Seed MVP categories.
- UI category navigation.

### Acceptance criteria

- Категории локализуются через i18n keys.
- Risky categories помечены restricted/legal review.

### Зависимости

- i18n.

### Что не делать

- Не включать аккаунты, ключи и пополнения общим флагом. Конкретная подкатегория может быть открыта только после `LEGAL_REVIEW_REQUIRED`, `PAYMENT_REVIEW_REQUIRED`, проверки правил исходной платформы и отдельного ADR.

### Подсказки для ИИ-агента

Свериться с `docs/LEGAL_REVIEW.md`.

### Проверка

API/category tests.

### Возможные риски

- Случайное открытие рискованных категорий.
