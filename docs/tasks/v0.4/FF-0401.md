# FF-0401: Расширить Creator Store domain до партнёрской атрибуции

Статус: planned
Версия: v0.4
Приоритет: P0
Компоненты: services/api, infra/migrations

### Цель

Автор может развить базовую live-only витрину `v0.3.5` до партнёрской витрины с attribution.

### Контекст

`v0.3.5` планирует базовые настройки витрины, секции, live-only правила, выбор продуктов, авторские подборки и базовые события партнёрских покупок. `v0.4` добавляет полноценный партнёрский слой: attribution, промокоды, disclosure и расширенную аналитику продаж от авторов.

### Что нужно сделать

- Расширить `creator_stores`/`store_items` для партнёрского attribution.
- Добавить связь с `AffiliateLink`, `PromoCode` и analytics events.
- Проверить partner disclosure.
- Сохранить product availability checks.

### Acceptance criteria

- Автор добавляет published partner product.
- Hidden product не продаётся из store.
- Disclosure required for partner product.

### Зависимости

- Creator profiles.
- Products.
- v0.3.5 live-only store settings, Studio products, Studio collections и activity events.

### Что не делать

- Не делать сложный recommendation engine.

### Подсказки для ИИ-агента

Store не должен копировать product полностью.

### Проверка

Store API tests.

### Возможные риски

- Продажа скрытого товара.
