# FF-0009: Отдельная VM для запуска FanFuel

Статус: completed
Версия: v0.0
Приоритет: P0
Компоненты: infra/docker, Docker Compose, документация запуска

## Цель

Создать отдельную Ubuntu VM на диске D:, перенести текущую рабочую копию и запустить приложения с PostgreSQL, Redis и MinIO.

## Acceptance criteria

- VM FanFuel создана отдельно от существующих VM и запускается без GUI.
- SSH работает по отдельному ключу; ключи и секреты находятся вне Git.
- Применены миграции, web/admin/widget и health endpoints доступны.
- Frontend использует собранные приложения вместо dev servers.
- Служебные порты привязаны к loopback; прикладные порты доступны из LAN будущей nginx VM.
- Запуск, проверки и оставшиеся ограничения описаны в handoff.

## Границы задачи

По уточнению пользователя nginx будет на отдельной VM. Дальнейшие настройки nginx, TLS и публичного маршрута отложены. Ранее созданная внутри FanFuel VM конфигурация зафиксирована в handoff и после уточнения не меняется. Реальные платежи не подключаются.

## Проверки

Docker Compose config/build/up, применение и повторный запуск миграций, HTTP и health smoke, проверка сетевых привязок и firewall.

Результат 2026-09-14: проверки успешны; девять контейнеров работают, пять миграций применены и повторный запуск идемпотентен. Web/API/WS/widget доступны из LAN, admin/DB/Redis/MinIO закрыты. Полный браузерный сценарий с публичными HTTPS API и WSS ожидает отдельного nginx/TLS; этот этап отложен пользователем.
