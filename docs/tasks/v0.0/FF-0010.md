# FF-0010: Маршрутизация FanFuel через nginx-edge-prod2

Статус: completed
Версия: v0.0
Приоритет: P0

## Цель

Добавить FanFuel в существующий edge, сохранив работающий LibreChat. Внешние TCP 80/443 должны направляться на edge; SSH наружу не публикуется.

## Реализация

- HTTP Host map и TLS SNI map на edge направляют домены FanFuel на порты 80/443 VM приложения.
- nginx приложения обслуживает web/API/WS/widget; прикладные контейнеры слушают loopback.
- Сертификат и обновление сертификата выполняются на FanFuel VM. Маленький системный диск edge не используется для certbot.

## Acceptance criteria

- HTTP FanFuel через edge возвращает страницу и API; запрещённые admin/mock пути закрыты.
- HTTPS FanFuel имеет валидный сертификат, HTTP перенаправляет на HTTPS.
- LibreChat продолжает отвечать по HTTPS.
- В роутере TCP 80/443 направлены на edge, TCP 22 не публикуется.
- Документация содержит проверки и оставшиеся ограничения.

## Текущее состояние

Host/SNI maps и существующие пробросы TCP 80/443 настроены. FanFuel и www отвечают по HTTPS с валидным сертификатом, HTTP возвращает 308, API/widget работают, admin/mock пути закрыты. LibreChat HTTPS сохранил HTTP 200. DHCP reservation FanFuel сохранён; certbot renew --dry-run успешен, автопродление включено.
