# FF-0354: Реализовать настройки витрины автора и live-only блоки

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, services/api, services/ws, infra/migrations

### Цель

Дать автору настройку витрины в Studio и показать карточки/подборки на публичной витрине только во время прямой трансляции.

### Что нужно сделать

- Реализовать `/studio/store` как настройки витрины автора.
- Добавить секции/подборки витрины с `visibility_rule`: `always`, `live_only`, `offline_only`.
- Добавить ручной live-state MVP: `offline`, `live`, `paused`.
- На публичной витрине показывать live-only секции только при `live`.
- Для paused/archived creator page показывать локализованное состояние временной недоступности.

### Acceptance criteria

- Автор может собрать секции витрины из своих подборок и published товаров.
- Live-only блоки скрыты, если автор offline.
- Live-state не подменяет будущую интеграцию со стриминговой платформой.
- Публичная витрина не продаёт hidden/unavailable products.

### Что не делать

- Не делать автоматическую интеграцию Twitch/YouTube/Kick без отдельной задачи.
- Не добавлять сложный recommendation engine.
- Не создавать real payout/commission UI.

### Проверка

- API tests для visibility rules и product availability.
- Browser smoke public creator store online/offline.
- WebSocket smoke для `creator.live_state_changed`, если realtime обновление входит в реализацию.

### Возможные риски

- Неверный live-state может скрыть или показать витрину в неподходящий момент.
- Партнёрские товары должны иметь disclosure, если используются до полного v0.4 attribution.
