# FF-0352: Разделить профиль пользователя и режимы автора/продавца

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, services/api, infra/migrations, packages/i18n

### Цель

Сделать `/me/profile` страницей пользователя, а настройки автора и продавца вынести в Studio/Seller sections.

### Что нужно сделать

- Профиль пользователя: аватар, display name, email/password settings entry, locale/theme entry.
- Entry points: избранное, мои отзывы, мои подборки.
- Entry points: стать автором, стать продавцом.
- Для существующих автора/продавца добавить pause/resume mode.
- Для страницы автора/продавца добавить archive/delete page flow как soft delete с audit log.
- Обновить navigation и role switcher, чтобы пользователь с несколькими ролями понимал текущий контекст.

### Acceptance criteria

- `/me/profile` не содержит Studio goals/widgets и seller product/settings forms.
- Пауза автора показывает на публичной странице состояние "страница временно недоступна" через i18n.
- Архивирование не удаляет историю заказов, донатов, отзывов, платежей и audit logs.
- Нельзя архивировать/скрывать seller mode, если это ломает активные обязательства; такие случаи получают понятный blocked state.

### Что не делать

- Не удалять физически финансовые или order-related данные.
- Не добавлять payouts, real payment UI или Seller Pro verification.
- Не смешивать account settings и creator storefront settings.

### Проверка

- Backend permission tests для owner-only endpoints.
- Frontend smoke для profile/settings/role navigation.
- Проверка i18n `ru`/`en`.

### Возможные риски

- Архивирование страницы продавца может конфликтовать с активными товарами и заказами.
- Пауза автора должна отключать публичные действия, но не терять данные.
