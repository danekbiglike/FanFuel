# FF-0360: Добавить Studio products и авторские подборки

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, services/api, infra/migrations

### Цель

Дать автору отдельные Studio-вкладки для выбора продуктов витрины и сборки авторских подборок, не смешивая это с пользовательскими подборками в профиле.

### Что нужно сделать

- Добавить `/studio/products` для выбора товаров, доступных для витрины автора.
- Показывать только published/eligible товары и статус доступности.
- Поддержать собственные товары автора и разрешённые партнёрские товары с disclosure.
- Добавить `/studio/collections` для сборки авторских подборок под витрину.
- Разрешить использовать пользовательские подборки автора как источник секций витрины.
- Синхронизировать выбор продуктов и подборок с `/studio/store`.

### Acceptance criteria

- Автор может выбрать товары для витрины без ручного ввода product ids.
- Hidden/unavailable products не попадают в публичную витрину.
- Партнёрские товары явно помечены и не скрывают disclosure.
- Авторские подборки можно использовать в live-only секциях витрины.

### Что не делать

- Не строить сложную рекламную биржу.
- Не делать multi-level affiliate network.
- Не обходить seller product moderation.

### Проверка

- API tests для eligibility и permissions.
- Browser smoke для пустого каталога, выбранных товаров и hidden product state.
- Проверка связи `/studio/products`, `/studio/collections` и `/studio/store`.

### Возможные риски

- Пользовательские и авторские подборки могут смешаться без ясного ownership.
- Партнёрские товары требуют аккуратного disclosure до полного v0.4 attribution.
