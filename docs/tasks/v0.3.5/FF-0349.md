# FF-0349: Обновить shared UI tokens и primitives под Aurora

Статус: partial  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: packages/ui, apps/web, apps/admin, apps/widget, packages/i18n

### Цель

Перевести базовый UI слой на Aurora tokens и material primitives, чтобы новые и существующие страницы использовали один визуальный контракт без page-specific hardcoded colors.

### Что нужно сделать

- Обновить `packages/ui/src/styles.css`: light/dark Aurora palette, glass tokens, gradient tokens, support/warm roles.
- Обновить `Button`, `IconButton`, `Badge`, `Tabs`, `Card`, `Panel`, `DashboardPanel`, `ProductCard`, `WidgetPreviewContainer`.
- Добавить или уточнить semantic variants: `primary`, `secondary/glass`, `support`, `ghost`, `danger`, `safeDeal`, `authorSupport`, `hit`, `new`, `verified`, `promo`.
- Проверить, что warm/orange не используется как default primary.
- Убедиться, что glass variants не применяются к таблицам и product cards по умолчанию.
- Сохранить i18n-only user-facing строки.

### Acceptance criteria

- Все новые визуальные роли доступны в light/dark через tokens.
- Product/dashboard/admin компоненты не зависят от конкретного hex.
- Focus/hover/active states читаемы в обеих темах.
- `prefers-reduced-motion` не ломает интерактивные состояния.

### Что не делать

- Не добавлять тяжёлую UI-библиотеку.
- Не вводить новый font dependency без отдельной задачи.
- Не делать полный redesign страниц в этой задаче.
- Не использовать glass как default Card style.

### Проверка

- `npm run typecheck --workspaces --if-present`.
- `npm run lint`.
- `git diff --check`.
- Ручная проверка token usage: `rg "#[0-9A-Fa-f]{3,8}|rgb\\(|rgba\\(" apps packages/ui`.

### Возможные риски

- Смена токенов может изменить старые экраны сильнее, чем ожидается.
- Недостаточный контраст glass variants может проявиться только на реальных страницах.
