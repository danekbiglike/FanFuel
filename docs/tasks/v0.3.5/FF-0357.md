# FF-0357: Собрать Studio shell и вкладку статистики

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, services/api, infra/migrations, packages/ui

### Цель

Сделать Studio отдельным рабочим кабинетом автора с понятными вкладками и базовой статистикой дохода, не смешивая её с профилем пользователя, балансом или выплатами.

### Что нужно сделать

- Реализовать `/studio` как shell с вкладками: статистика, последние события, настройка донатов, витрина автора, виджеты, продукты, подборки.
- Добавить `/studio/statistics` с графиком динамики дохода.
- Поддержать фильтры графика: период, источник `donations`, источник `partner_products`, источник `all`.
- Считать статистику только из реальных domain events/mock MVP events без fake metrics.
- Хранить денежные значения только в minor units и явно отделять analytics от `Wallet`, `BalanceTransaction` и payouts.
- Добавить empty/loading/error states и mobile layout для графика.

### Acceptance criteria

- Автор видит Studio как отдельный кабинет, а не блок внутри `/me/profile`.
- График показывает донаты и доход от партнёрских товаров раздельно или вместе.
- UI не называет статистику доступным балансом и не обещает выплату.
- Фильтры не ломают `ru`/`en`, mobile и light/dark.

### Что не делать

- Не добавлять payout UI, ledger, real balance или fiscalization.
- Не показывать fake revenue при отсутствии событий.
- Не делать глубокую BI-аналитику, cohorts или рекламные отчёты.

### Проверка

- API tests для фильтров статистики и minor units.
- Component/browser smoke для пустого графика, одного источника и нескольких источников.
- `git diff --check` и visual QA для mobile/light/dark.

### Возможные риски

- Пользователь может принять график дохода за доступные к выводу деньги.
- Неверная агрегация партнёрских заказов может исказить вклад автора.
