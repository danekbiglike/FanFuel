# FF-0353: Добавить избранное, мои отзывы и пользовательские подборки

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, services/api, infra/migrations, packages/i18n

### Цель

Дать обычному пользователю личные потребительские функции: избранное, свои отзывы и подборки товаров/авторов.

### Что нужно сделать

- Добавить `Favorite`, `UserCollection`, `CollectionItem`.
- Реализовать `/me/favorites`, `/me/reviews`, `/me/collections`.
- Разрешить пользователю создавать подборки независимо от creator role.
- Поддержать public/private статус подборки.
- Добавить empty/loading/error states.

### Acceptance criteria

- Пользователь может сохранить товар, автора или подборку в избранное.
- Пользователь видит свои опубликованные/скрытые отзывы.
- Пользователь может создать подборку и добавить туда published товары.
- Private подборки не видны публично.

### Что не делать

- Не делать ML-рекомендации.
- Не добавлять социальную сеть, подписки и комментарии к подборкам.
- Не показывать fake products.

### Проверка

- API tests для owner permissions.
- Frontend smoke для empty и populated states.
- Mobile/light/dark visual QA.

### Возможные риски

- Public подборки могут стать источником спама, поэтому нужна moderation-ready модель статусов.
