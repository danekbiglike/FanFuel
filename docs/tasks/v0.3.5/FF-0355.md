# FF-0355: Добавить widget trigger rules и asset-настройки

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, apps/widget, services/api, services/ws, packages/sdk

### Цель

Позволить автору создавать и настраивать виджеты под конкретные задачи: товар, группу товаров, покупку спонсорских товаров или сумму доната.

### Что нужно сделать

- Добавить `WidgetAlertRule` с trigger type: donation amount, product, product group, store collection, purchase event.
- Поддержать upload/выбор image/gif/animation assets через безопасный file flow.
- Добавить preview на mock events в Studio.
- Обновить widget config schema versioning.
- События не должны содержать секреты или лишние персональные данные.

### Acceptance criteria

- Автор может настроить отдельный alert для товара.
- Автор может настроить alert для группы товаров или подборки.
- Автор может настроить alert по порогу суммы доната.
- Preview использует mock events и не требует настоящего widget token.

### Что не делать

- Не разрешать менять настройки через public widget URL.
- Не строить полноценный animation editor.
- Не логировать raw token или приватные данные покупателя.

### Проверка

- API tests для rule matching.
- Widget rendering smoke для donation/purchase mock events.
- Проверка `prefers-reduced-motion`.

### Возможные риски

- Неправильный rule priority может показывать не тот alert.
- Большие gif/animation assets могут ухудшить OBS performance.
