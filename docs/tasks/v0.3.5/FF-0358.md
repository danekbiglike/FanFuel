# FF-0358: Добавить последние события и bot-backed channel subscriptions

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, services/api, services/ws, services/worker, infra/migrations

### Цель

Дать автору ленту последних событий в Studio: все события, донаты, подписки на каналы и покупки партнёрских товаров. Подписки на YouTube, Twitch и Telegram должны приходить через безопасный bot/integration слой.

### Что нужно сделать

- Добавить `/studio/events` с подвкладками: все события, донаты, подписки на каналы, покупки партнёрских товаров.
- Добавить доменную модель `CreatorActivityEvent` для unified activity feed.
- Добавить `CreatorChannelIntegration` для YouTube, Twitch и Telegram bot connections.
- Описать безопасный ingestion событий от ботов через подписанные internal endpoints или очередь.
- Показывать статус интеграции: not connected, connecting, active, paused, error, revoked.
- Не раскрывать platform tokens, viewer private data и raw payload в UI.

### Acceptance criteria

- Автор видит последние события в одном месте и может отфильтровать их по типу.
- События подписок имеют source platform и channel id/name без лишних приватных данных.
- Покупки партнёрских товаров попадают в feed как отдельный тип события.
- Неактивный бот показывает понятное состояние подключения, а не пустой feed без объяснения.

### Что не делать

- Не хранить platform bot secrets во frontend.
- Не делать scraping вместо официальных bot/API/webhook возможностей.
- Не обещать production-поддержку YouTube/Twitch/Telegram без platform/security review.
- Не показывать raw provider/bot payload пользователю.

### Проверка

- API tests для фильтров event feed и permissions.
- Worker/ingestion tests для подписи события и dedupe.
- Browser smoke для пустого feed, активной интеграции и ошибки интеграции.

### Возможные риски

- У платформ разные правила, rate limits и требования к OAuth/bot permissions.
- Channel subscription events могут приходить с задержкой или дубликатами.
