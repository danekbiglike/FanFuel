# FF-0359: Добавить настройки донатов, модерацию и spam-фильтр

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, services/api, services/ws, infra/migrations

### Цель

Дать автору отдельную вкладку настройки донатов: суммы, сообщения, аудиосообщения, озвучка, модерация и спам-фильтр.

### Что нужно сделать

- Добавить `/studio/donation-settings`.
- Добавить `CreatorDonationSettings` с presets сумм, min/max, currency, message max length.
- Добавить настройки аудиосообщений: разрешённые категории и минимальная сумма.
- Добавить настройки озвучки: разрешённые категории, минимальная сумма и moderation mode.
- Добавить moderation queue policy: auto-approve, hold-for-review, blocked.
- Добавить spam-filter policy: частота, repeated text, blocked words, link policy.
- Все user-facing ошибки и подписи вынести в i18n.

### Acceptance criteria

- Автор может настроить суммы донатов и ограничения сообщений.
- Audio/TTS включаются только для выбранных категорий и суммы от заданного порога.
- Спам-фильтр и модерация применяются до публикации alert в OBS.
- Настройки не хардкодят платёжного провайдера и не меняют payment status.

### Что не делать

- Не реализовывать real provider payments или fiscalization.
- Не делать автоматическую токсичность/ML-модерацию как обязательный MVP.
- Не хранить аудиофайлы или TTS provider secrets без security review.

### Проверка

- API tests для validation настроек и permission owner-only.
- Donation flow tests для message length, audio/TTS thresholds и moderation hold.
- Widget smoke: held donation не уходит в публичный alert.

### Возможные риски

- Слишком жёсткий spam-filter может блокировать нормальные донаты.
- Audio/TTS может быть дорогим или рискованным без отдельной provider policy.
