# FF-0356: Добавить группы виджетов и OBS placement zones

Статус: planned  
Версия: v0.3.5  
Приоритет: P0  
Компоненты: apps/web, apps/widget, services/api, services/ws, packages/sdk

### Цель

Дать автору вкладку Studio для групп виджетов, чтобы разные типы алертов можно было расположить в разных местах OBS.

### Что нужно сделать

- Добавить `WidgetGroup` с read-only token, layout config и зонами placement.
- Разрешить размещение alert types по зонам: center, top_right, top_left, bottom_right, bottom_left, custom normalized rect.
- Связать `WidgetAlertRule` с группой или зоной.
- Поддержать preview всей группы в Studio.
- Обновить OBS widget route для group mode.

### Acceptance criteria

- Донаты можно настроить в центральной зоне.
- Покупки спонсорских товаров можно настроить в правой верхней зоне.
- Public widget group URL read-only и не раскрывает настройки редактирования.
- Token виден только при создании/ротации.

### Что не делать

- Не делать drag-and-drop редактор OBS-сцены.
- Не создавать public settings через token URL.
- Не смешивать widget group token с API auth token.

### Проверка

- API tests для group ownership и token rotation.
- Widget smoke для нескольких зон.
- Mobile/desktop Studio preview QA.

### Возможные риски

- Слишком свободная layout config может ломать OBS browser source.
- Несколько зон могут конфликтовать по z-index и очереди событий.
