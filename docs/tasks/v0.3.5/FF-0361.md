# FF-0361: Расширить Studio widgets до каталога категорий и presets

Статус: planned  
Версия: v0.3.5  
Приоритет: P1  
Компоненты: apps/web, apps/widget, services/api, services/ws, packages/sdk

### Цель

Сделать вкладку виджетов в Studio не только списком токенов, а каталогом задач: оповещения, статистика, сбор средств, товары, цикличные промо и будущие preset-типы.

### Что нужно сделать

- Расширить `/studio/widgets` категориями: оповещения, статистика, сбор средств, товары, цикличные промо, прочие.
- Связать категорию "оповещения" с `WidgetAlertRule` и `WidgetGroup`.
- Добавить widget preset registry с schema versioning.
- Поддержать виджет статистики как read-only overlay на основе Studio statistics.
- Поддержать fundraising widget на базе donation goals.
- Поддержать product widgets и цикличные промо-плашки "зайти на сайт" без произвольного кода.

### Acceptance criteria

- Автор выбирает widget type из понятной категории.
- Каждый preset имеет preview, supported events и limitations.
- Widget config валидируется schema, а public URL остаётся read-only.
- `prefers-reduced-motion` учитывается для animated presets.

### Что не делать

- Не разрешать произвольный JS/HTML/CSS в виджете.
- Не делать полноценный visual animation editor.
- Не показывать приватные order/customer data в product widgets.

### Проверка

- API tests для preset schema и permissions.
- Widget smoke для alert, statistics, fundraising и product presets.
- Browser smoke для каталога категорий и preview.

### Возможные риски

- Слишком много preset-типов может перегрузить первый Studio MVP.
- Цикличные промо должны быть заметны в OBS, но не превращаться в навязчивую рекламу.
