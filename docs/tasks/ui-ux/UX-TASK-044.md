# UX-TASK-044 — публичная тестовая главная с Ойли

Статус: `IMPLEMENTED`. Версия: `playground-v0.1`. Страница: `PAGE-PLAYGROUND`. Route: `https://playground.fanfuel.ru/`. Дата: 2026-09-24.

## Задача

Показать тестовую главную на существующем сервере FanFuel без отдельного работающего приложения. Вход, поиск, категории и карточки товаров — явный макет без API и покупок. Ойли можно схватить, деформировать, отпустить на видимые карточки и настраивать прямо на странице.

## Реализация

- Vite собирает страницу из `packages/pencil-engine/playground` в статические файлы; nginx VM FanFuel отдаёт их с отдельного host. Публичный edge передаёт Host/SNI на ту же VM.
- Физика и карандашный рендер используют `packages/pencil-engine/src`; Canvas обновляет только область Ойли. Worker выполняет рендер; физика идёт фиксированным шагом 120 Гц, визуальный кадр до 24 к/с в движении и 2 раза/с в покое.
- Панель меняет кисть, толщину, плотность, зерно, нажим, размах нажима, неровность, сужение, мягкость и «живое» зерно. Доступны сброс, темы и ru/en.
- Видимые карточки берутся из DOM после scroll/resize; верхняя граница не позволяет выбросить персонажа за экран.

## Acceptance criteria

- `https://playground.fanfuel.ru/` отвечает HTTPS 200 с корректным сертификатом; основной `https://fanfuel.ru/` продолжает отвечать 200.
- Вход, поиск, категории и товары не отправляют запросы и не создают заказов.
- Ойли перемещается мышью и касанием, попадает на видимые карточки и пол; изменения ползунков видны без перезагрузки.
- Работают ru/en, light/dark, клавиатурный сдвиг персонажа, `prefers-reduced-motion`; нет горизонтального переполнения на 390 и 1440 px.
- Рендер не создаёт отдельный серверный процесс, публичный vhost отдаёт только статические файлы, API отсутствует, индексация отключена.

## Дальше

Художественное принятие контура и полноценная форма Ойли остаются отдельной проверкой владельца. Для переноса на реальную главную нужны интеграция с настоящими карточками, независимые части лица/канистры и замеры на слабом устройстве. Текущая тестовая витрина не является каталогом и не подтверждает готовность commerce-функций.
