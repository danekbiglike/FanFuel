# UX-TASK-026 — Дожать иерархию creator-commerce витрины `/marketplace`

Статус: completed  
Приоритет: P0  
Версия: v0.3.5  
Связанные страницы: PAGE-MARKETPLACE, PAGE-HOME, PAGE-CREATORS-DIRECTORY, PAGE-SAFE-DEAL

## Контекст

После `UX-TASK-025` главная снова показывает creator-commerce механику, большой hero search и связь товара с авторской витриной. Следующая проблема — слабая визуальная иерархия: hero, карточки механики, категории, товарные обложки, витрины авторов, блоки для авторов/продавцов и безопасность местами выглядят одинаково важными и слишком шаблонными.

## Что сделать

- Усилить hero без смены структуры: крупнее H1, больше воздуха, более сильный акцент на строке "Поддерживай любимых".
- Уточнить hero lead: цифровые товары, донаты, OBS-алерты и витрины авторов в одной платформе.
- Сделать быстрые направления под поиском тише, чтобы они не конкурировали с главным поиском и CTA.
- Добавить в hero-card явную мини-цепочку "зритель покупает → продавец выполняет → автор получает поддержку".
- Усилить блок "Покупка может быть поддержкой": добавить визуальную цепочку "Товар → Автор → Поддержка", увеличить карточки и сделать смысловые заголовки заметнее.
- В категориях добавить примеры товаров/сценариев и визуально развести направления через разные мини-превью.
- В product media вернуть осмысленные category mock-preview для пустых cover slots без подмены реальных seller cover image.
- В featured-блоке явно показать "Этот товар добавили 14 авторов" и подпись про поддержку выбранного автора через витрину или промокод.
- Сделать первую витрину автора featured, а следующие витрины компактнее, чтобы блок не ощущался тяжёлой повторяющейся лентой.
- Усилить блоки для авторов и продавцов: крупнее заголовки, заметнее mockup/flow, конкретнее выгода продавца через витрины авторов.
- Переписать safety cards на пользовательские формулировки: оплата внутри заказа, рейтинг, условия заказа и спор.

## Acceptance criteria

- Первый экран считывается как marketplace + creator support, а не как обычный тёмный каталог.
- Главный поиск остаётся центральным действием, быстрые направления не выглядят равными поиску CTA.
- Механика поддержки автора видна в hero и сразу после hero как цепочка.
- Категории помогают распознать ассортимент через примеры.
- Карточки товаров получают различимые preview-типы, но реальные cover image продавца остаются выше декоративного preview.
- Featured-блок объясняет, почему товар популярен в витринах авторов.
- Витрины авторов визуально легче: первая карточка может быть крупнее, остальные компактнее.
- SafeDeal объясняется простым пользовательским языком, без provider/legal/internal терминов.
- Все новые строки добавлены в `ru` и `en`.
