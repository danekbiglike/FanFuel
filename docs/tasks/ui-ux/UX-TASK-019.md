# UX-TASK-019: Уплотнить `/marketplace` в компактную creator-commerce витрину

Статус: completed  
Приоритет: P0  
Версия: v0.3.5  
Связанные страницы: PAGE-HOME, PAGE-MARKETPLACE  
Связанные задачи: UX-TASK-017, UX-TASK-018, FF-0350

## Контекст

`/marketplace` не должен быть полной презентацией всей платформы. Страница должна быстро отвечать, что здесь можно купить, чем FanFuel отличается от обычного маркетплейса, почему покупка проходит понятнее и безопаснее, и что делать дальше.

## Scope

- Сократить структуру `/marketplace` до витринного порядка: hero, поиск и категории, хит в витринах авторов, популярные товары, подборки авторов, польза для трёх аудиторий, компактный SafeDeal, общий CTA и короткий FAQ.
- Убрать с главной большие лендинговые секции для стримеров и продавцов, большой поиск автора, ленту новых товаров и длинные SafeDeal/FAQ объяснения.
- Не создавать отдельные `/marketplace/catalog`, `/marketplace/search`, `/creators`, `/streamers`, `/sellers`, `/safe-deal` в рамках этой задачи.
- Переписать публичные SafeDeal-тексты без внутренних `provider/legal review` формулировок.
- Заменить пустые градиентные product preview на осмысленные категорийные псевдо-превью.

## Acceptance criteria

- Новый пользователь за первые 10-15 секунд понимает, что продаются цифровые товары, есть авторы и стримеры, покупка может поддерживать автора, есть SafeDeal и проверенные продавцы.
- Страница не ощущается как обычный каталог и не превращается в длинный платформенный лендинг.
- Mobile остаётся компактным: hero, CTA, поиск, карточка покупки через автора, категории и горизонтальные товарные секции.
- Пользовательские тексты идут через i18n.
- Отдельные future/payment-review маршруты не создаются без обновления статусов tracker/spec.
