# UX-TASK-027: Перепрошить creator-commerce иерархию `/marketplace`

Статус: completed  
Приоритет: P0  
Версия: v0.3.5  
Связанные страницы: PAGE-HOME, PAGE-MARKETPLACE  
Связанные файлы: `apps/web/src/app/marketplace/page.tsx`, `apps/web/src/app/globals.css`, `apps/web/src/components/app-chrome.tsx`, `packages/i18n/locales/*/common.json`

## Контекст

Текущая `/marketplace` уже показывает большой hero search, витрины авторов, категории и безопасность, но визуальная структура всё ещё читается как набор равноважных тёмных карточек. Нужно сделать creator-commerce механику скелетом страницы: товар, витрина или промокод автора, безопасная покупка, поддержка автора и заказ продавцу.

## Требования

- Сохранить единый бренд `FanFuel` во всём UI.
- Header держать как sticky glass bar высотой 64px с навигацией: Маркет, Авторы, Для авторов, Для продавцов, Безопасность.
- Hero оставить search-first: крупный H1, большой поиск, три быстрых действия и тихая строка направлений.
- Hero demo должен явно показывать автора, цель, товар, промокод, безопасную сделку и цепочку `Зритель покупает → продавец выполняет → автор получает поддержку`.
- Блок "Покупка может быть поддержкой" оформить как визуальную цепочку из трёх шагов, а не как обычные равные карточки.
- В категориях убрать абстрактные декоративные фигуры; оставить понятные иконки, описание, примеры и стабильные карточки.
- Featured-блок "Популярно в витринах авторов" сделать единым proof-module: слева товар, справа авторы и явное доказательство "товар добавили 14 авторов".
- Product cards держать крупными и сканируемыми: 4/3/2/1 колонки, media 16:10, максимум два бейджа.
- Витрины авторов сделать легче: первая витрина может быть featured, остальные компактнее; на главной не больше трёх товаров в витрине.
- Блоки для авторов и продавцов должны выглядеть как отдельные крупные смысловые секции, а не обычные мелкие карточки.
- Безопасность формулировать пользовательским языком: безопасная сделка, оплата внутри заказа, рейтинг, условия заказа, спор.

## Acceptance criteria

- За первые 5 секунд пользователь понимает, что FanFuel — это не только каталог товаров, а creator-commerce механика с авторами, витринами, промокодами и безопасной покупкой.
- Категории, товары, featured-модуль, витрины авторов и безопасность визуально различаются по роли.
- Нет скрытых фильтров или странных кликов: поиск ищет, категории ведут на категории, карточки открывают сущности.
- Карточки не ломаются на desktop/tablet/mobile и не используют absolute-декор, который меняет форму при resize.
- Пользовательские тексты добавлены через i18n.

## Проверки

- `npm run typecheck --workspaces --if-present`
- `npm run lint`
- `npm run build --workspaces --if-present`
- Visual QA `/marketplace` на desktop и mobile.

## Результат

- Header закреплён как sticky glass bar 64px; desktop guest burger скрыт, mobile сохраняет поиск и меню.
- Hero, demo-card и блок поддержки показывают механику `товар → витрина/промокод автора → безопасная покупка → поддержка автора → заказ продавцу`.
- Категории очищены от абстрактных фигур и стабилизированы как 4/2/1 grid с понятными иконками и примерами.
- Featured-блок стал единым proof-module с товаром, авторами, промокодами и явным тезисом про 14 витрин.
- Product cards и витрины авторов стабилизированы по grid/adaptive rules; обычные товары остаются кликабельными целиком.
- Safety и role sections разделены визуально и используют пользовательский язык без внутренних provider/legal формулировок.
