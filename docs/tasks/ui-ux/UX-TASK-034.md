# UX-TASK-034: Скрытый игровой режим и первая web-игра

Статус: completed

Приоритет: P2

Версия: v0.3.5

Route: `/gaming`

## Контекст

По прямому запросу владельца проекта в `apps/web` нужен скрытый режим с автономными web-играми. Режим не является публичным продуктовым модулем FanFuel, не показывается в основной навигации и не использует backend.

## Scope

- Добавить скрытый route `/gaming` без ссылки из header, footer и marketplace.
- Реализовать первую игру в жанре match-3 с оригинальным визуальным слоем FanFuel.
- Добавить уровни, цели, ограничение ходов, локальные монеты, комбо, специальные фишки и усилители.
- Сохранять прогресс только в `localStorage` текущего браузера.
- Поддержать ru/en, light/dark, mobile/desktop, клавиатуру и `prefers-reduced-motion`.
- Не добавлять API, БД, платежи, покупки за реальные деньги, лидерборды и публичный профиль игрока.

## Игровая модель

- Поле `8 × 8`, обмен только соседних фишек.
- Совпадение трёх и более фишек очищает линию и заполняет цели уровня.
- Линия из четырёх создаёт линейный ускоритель, линия из пяти — призму.
- Серии каскадов увеличивают очки и заряжают суперсилу.
- Монеты выдаются только за прохождение уровня и не имеют денежной ценности.
- Усилители расходуют только локальную игровую валюту/инвентарь.

## Acceptance criteria

- Route не отображается в публичной навигации и открывается только по прямому URL.
- Игра не делает сетевых запросов и работает после загрузки frontend bundle.
- На старте нет готовых совпадений, на поле есть допустимый ход.
- Невалидный обмен возвращает фишки и не списывает ход.
- Валидный обмен обрабатывает каскады, цели, очки и специальные фишки.
- Завершение уровня открывает следующий и сохраняет прогресс локально.
- Проигрыш позволяет повторить уровень без повреждения прогресса.
- Интерфейс работает на 320/390/768/1280 px, в light/dark и с клавиатуры.
- Все пользовательские тексты находятся в ru/en i18n-словарях.

## Риски и ограничения

- Очистка данных сайта удалит игровой прогресс.
- Прогресс не синхронизируется между устройствами.
- Игровые монеты нельзя показывать как баланс, награду платформы или средство оплаты.
