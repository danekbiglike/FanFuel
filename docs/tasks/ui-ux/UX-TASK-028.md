# UX-TASK-028: Поднять товарные сценарии в `/marketplace`

Статус: completed  
Приоритет: P0  
Версия: v0.3.5  
Связанные страницы: PAGE-HOME, PAGE-MARKETPLACE  
Связанные файлы: `apps/web/src/app/marketplace/page.tsx`, `apps/web/src/app/globals.css`, `packages/i18n/locales/*/common.json`

## Контекст

После `UX-TASK-027` главная `/marketplace` стала понятнее как search-first creator-commerce страница, но реальные товарные сценарии появляются слишком поздно. Пользователь сначала видит hero, затем большой блок объяснения механики и категории, а только потом товары и авторские витрины. Для marketplace-страницы это риск: покупатель должен быстро увидеть ассортимент, а стример и продавец должны увидеть creator-commerce механику через конкретные подборки и товары.

## Требования

- Сохранить бренд `FanFuel` без смешивания с `FunFuel`.
- Сохранить hero с большим поиском и demo покупки через витрину автора.
- Заменить большой блок "Покупка может быть поддержкой" на компактный flow-bar: `Товар найден → покупка через автора → автор получает поддержку`.
- Сразу после flow-bar добавить быстрый товарный вход: категории слева и блок "Сейчас покупают" справа.
- Поднять "Подборки авторов" выше обычного блока популярных товаров.
- Сделать подборки авторов компактными карточками: автор, название подборки, цель, промокод, 2 товара и CTA.
- Переделать "Популярно в витринах авторов" в ровный proof-module без сложных внутренних форм.
- Сохранить product cards как кликабельные карточки с media 16:10, рейтингом с количеством отзывов, продавцом и максимум двумя бейджами.
- Убрать абстрактные декоративные фигуры из категорий; оставить понятные иконки, короткое описание и примеры.
- Не добавлять скрытые фильтры на главной: быстрые направления ведут на явные страницы.

## Acceptance criteria

- В первые секунды пользователь видит не только концепцию, но и ранний товарный вход: категории и "Сейчас покупают".
- Структура `/marketplace`: hero, compact flow, быстрый товарный вход, подборки авторов, популярно в витринах авторов, популярные товары, блоки для авторов/продавцов, безопасность, финальный CTA.
- Подборки авторов стали ранним creator-commerce доказательством, а не тяжёлым нижним блоком.
- Категории не содержат абстрактных псевдо-фигур и не ломаются при resize.
- Product grid остаётся стабильным на desktop/tablet/mobile.
- Все новые пользовательские строки добавлены через i18n.

## Проверки

- `npm run lint`
- `npm run typecheck --workspaces --if-present`
- `npm run build --workspaces --if-present`
- Visual QA `/marketplace` на desktop и mobile.

## Результат

- Большая объясняющая секция поддержки заменена compact flow-bar сразу после hero.
- Добавлен быстрый товарный вход: 6 категорий и блок "Сейчас покупают" с 3 компактными товарами при наличии данных.
- Подборки авторов подняты выше proof-module и популярного грида; каждая карточка показывает автора, цель, промокод, 2 товара и CTA.
- Featured-блок сохранён как proof-module "Популярно в витринах авторов".
- Product grid остался 4/3/2/1, карточки кликабельны целиком, бейджи ограничены.
- Категории очищены от абстрактных декоративных фигур и используют понятные иконки/примеры.
