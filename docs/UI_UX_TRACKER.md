# UI/UX Tracker

Главный рабочий трекер интерфейса FanFuel. Перед созданием или изменением страниц агент должен свериться с этим документом, `docs/PAGE_MAP.md`, `docs/PAGE_SPECS.md`, `docs/USER_FLOWS.md`, `docs/UX_IMPLEMENTATION_STATUS.md` и `docs/DO_NOT_BUILD_YET.md`.

## Статусы

- `NOT_PLANNED` — страница или фича не запланирована.
- `FUTURE` — нужна в будущем, сейчас не делать.
- `PLANNED` — запланирована для ближайших версий, но не реализована.
- `IN_PROGRESS` — в работе.
- `IMPLEMENTED` — реализована и соответствует текущему spec.
- `PARTIAL` — реализована частично.
- `NEEDS_REWORK` — есть в коде, но UX/структура не соответствуют целевому spec.
- `BLOCKED` — заблокирована зависимостью.
- `LEGAL_REVIEW` — требует юридической проверки.
- `PAYMENT_REVIEW` — требует проверки платёжной модели.
- `DESIGN_REVIEW` — требует дизайн-проверки.
- `UX_REVIEW` — требует UX-проверки.
